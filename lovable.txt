### **1. Project Structure (Where Everything Lives)**

Your project is split into two main parts: the **Brain (Backend)** and the **Face (Frontend)**.

* **Root Folder:** `C:\Users\aryan\lexsaksham\`

#### **A. The Backend (The Brain)**
* **Location:** `backend/ai_service/`
* **Main File:** `app.py` (This is the server that runs everything).
* **Port:** `http://127.0.0.1:5000` (Localhost Port 5000)
* **Key Folders:**
    * `models/`: Stores your trained AI models (LegalBERT, T5, Judgment Model).
    * `indexes/`: Stores the FAISS index (`judgments.index`) for searching case law.
    * `datasets/`: Stores your raw data (`supreme_judgments.jsonl`).

#### **B. The Frontend (The Face)**
* **Location:** `frontend/`
* **Main File:** `src/App.jsx` (This is the UI code you see in the browser).
* **Port:** `http://localhost:5173` (Localhost Port 5173 - standard for Vite apps)
* **Key Folders:**
    * `src/components/`: Reusable parts like the Sidebar and Analysis Card.
    * `src/pages/`: The main screens (Login, Dashboard, Analysis).
    * `src/services/`: The `api.js` file that talks to the backend.

---

### **2. How They Connect (The "Wiring")**

The Frontend and Backend are separate programs running on your computer at the same time. They talk to each other using **HTTP Requests** (like a web browser talking to a website).

1.  **User Action:** You click "Analyze Contract" in the Frontend (Port 5173).
2.  **Request:** The Frontend sends a message (POST request) to `http://127.0.0.1:5000/analyze_document`.
3.  **Processing:** The Backend (`app.py`) receives the text.
    * It asks **LegalBERT**: "Is this risky?"
    * It asks **T5**: "Simplify this."
    * It asks **FAISS**: "Find similar cases."
4.  **Response:** The Backend sends a JSON package back to the Frontend with all the answers.
5.  **Display:** The Frontend reads the JSON and updates the screen (showing the red/green badges and text).

---

### **3. Minute Details You Need to Know**

* **CORS (Cross-Origin Resource Sharing):** This is the security rule that lets Port 5173 talk to Port 5000. In `app.py`, the line `CORS(app)` handles this. If you ever see a "CORS Error," it means this bridge is broken.
* **Virtual Environment (`venv`):** Your backend runs inside a special isolated box called `venv`. You **must** always activate this (`.\venv\Scripts\activate`) before running `python app.py`, or it won't find your libraries.
* **Node Modules:** Your frontend relies on thousands of tiny libraries stored in `node_modules`. You never touch this folder, but you need to run `npm install` if you ever move the project to a new computer.

### **4. Summary for Your Mental Model**

* **You run TWO terminals:**
    * **Terminal 1 (Backend):** Runs Python. It's the engine room. It stays open and prints logs like `POST /analyze 200 OK`.
    * **Terminal 2 (Frontend):** Runs Node.js. It serves the visual website.
* **The Bridge:** The `axios` library in your frontend code is the messenger that carries data back and forth.

This architecture is industry-standard for modern web applications (MERN stack style, but with Python for AI). You are building a professional-grade system.
